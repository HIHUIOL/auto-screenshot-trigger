# 曙光OBS炼化自动截图

从视频采集源（OBS 虚拟摄像头 / 采集卡 / 物理摄像头）持续读帧，与预先框选的基准图像做相似度比对，当画面连续命中时自动截图保存。

## 功能特性

- DirectShow 枚举所有视频输入设备（物理摄像头、采集卡、OBS 虚拟摄像头）
- 框选基准区域，按像素相似度实时判定命中
- 连续 N 帧命中才触发，避免误触
- 金币区二级去重，防止重复保存同一画面
- 多线程流水线：采集 → 并行比对 → 顺序落盘
- MMCSS 多媒体调度提权，降低采集抖动
- 参数实时调节面板：四条滑条调色 + 按键切换格式/分辨率/帧率/缓冲

## 环境要求

- Windows 10 / 11（x64）
- Visual Studio 2022（含「使用 C++ 的桌面开发」工作负载）
- OpenCV 4.12（`opencv_world4120.lib` / `opencv_world4120.dll`）

## 编译

用 Visual Studio 打开 `曙光OBS炼化自动截图.slnx`，选择 **x64 / Release** 生成。

生成的 exe 需与 `opencv_world4120.dll` 放在同一目录才能运行。

## 使用

运行 `曙光OBS炼化自动截图.exe`，主菜单：

| 序号 | 功能 |
|:---:|---|
| 1 | 获取主目标基准样本（框选要识别的区域） |
| 2 | 启动监控（纯后台运作） |
| 3 | 启动监控调试（预览画面 + 绿框/红框标注） |
| 4 | 选择视频源设备 |
| 5 | 更改判定参数（相似度阈值 / 连续判定帧数） |
| 6 | 设置金币判定区（防重复保存专用） |
| 7 | MMCSS 多媒体调度开关 |
| 8 | 摄像头参数调节 |
| 9 | 帮助说明 |

**推荐流程**：`4` 选设备 → `8` 调画质与格式 → `1` 框选样本 → `6` 框选金币区（可选）→ `3` 调试确认 → `2` 正式运行。

### 预览窗口按键（选项 1 / 6）

| 按键 | 作用 |
|---|---|
| `0` | 刷新画面 |
| `空格` / `回车` | 确认当前画面 |
| `ESC` | 取消操作 |
| 鼠标拖拽 | 框选区域 |

### 参数调节面板按键（选项 8）

| 按键 | 作用 |
|---|---|
| `↑` / `↓` | 切换视频格式 |
| `←` / `→` | 切换分辨率 |
| `+` / `-` | 调整帧率 |
| `[` / `]` | 调整缓冲帧数 |
| `0` | 恢复默认 |
| `A` | 自动检测设备支持的能力 |
| `ESC` | 保存并退出 |

## 配置文件

首次运行后在程序目录生成 `曙光截图配置.ini`（UTF-8 编码），可手动编辑阈值、颜色容差、JPEG 质量等参数。

截图默认保存至 `ScreenShot\` 目录，按数字序号命名。
